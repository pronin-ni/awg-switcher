The upstream `wireproxy v2.1.0` tag is annotated but unsigned (`verification.verified=false`), which remains a provenance risk even though the Docker build verifies the pinned commit and compiles from that source. The initial Git history was scanned with Gitleaks (zero findings); CI is configured to scan full history on every run. `sbom.cdx.json` covers the Go module dependency graph, while `image-sbom.cdx.json` is generated from the Linux/amd64 image.

The dependency license inventory was generated with `google/go-licenses v1.6.0` against the exact v2.1.0 source commit after applying the pinned `golang.org/x/net v0.62.0` and `golang.org/x/crypto v0.58.0` security updates. It reported only the listed permissive licenses; it emitted warnings that architecture-specific assembly files could not be inspected. Manual legal review is not provided by this software project and automated classification is not a legal opinion.
